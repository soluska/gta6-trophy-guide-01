Leonida Trophy Guide — an offline web app that guides and tracks all 55 Grand Theft Auto VI trophies on PlayStation 5: every official name, description and grade, a guide to each in our own words that cites its sources, a platinum roadmap (about 200 hours, difficulty 4/10), the one possibly missable trophy flagged, and a checklist with saved progress, export/import, filters and a spoiler setting that hides story trophies until earned.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
